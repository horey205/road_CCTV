# 🚗 출근길 도로 CCTV 모니터링 시스템

스마트폰 브라우저에서 출근길 주요 도로 CCTV 4곳을 실시간 모니터링할 수 있는 반응형 웹 대시보드입니다.

## 📍 모니터링 대상 (핵심 4개 지점)
1. **[수도권제1순환선] 성남삼평교** (판교 ↔ 구리/퇴계원 방면)
2. **[수도권제1순환선] 성남삼평교2** (성남 ↔ 일산/판교 방면)
3. **[경수대로] 골사그네** (수원 ↔ 안양/의왕 경수대로)
4. **[과천봉담선] 월암IC** (봉담 ↔ 과천 도시고속화도로)

---

## 🚀 로컬 실행 방법 (PC & 동일 와이파이 스마트폰)

1. 파이썬 프록시 서버 실행:
   ```bash
   python server.py
   ```
2. 웹 브라우저 접속:
   - PC: `http://localhost:8000/`
   - 모바일: `http://192.168.0.6:8000/` (같은 Wi-Fi 공유기 접속 시)

---

## 🌐 GitHub Pages 배포 시 참고
- GitHub Pages는 정적 HTML 호스팅이므로, 외부 공공 API(ITS) 및 네이버 지도 API의 CORS 및 인증 헤더를 우회할 백엔드 프록시가 필요합니다.
- 동봉된 `cloudflare-worker.js`를 무료 Cloudflare Worker에 복사하여 붙여넣으신 후 배포하시면, PC를 켜두지 않고도 언제 어디서든 GitHub Pages 주소로 실시간 영상을 감상하실 수 있습니다.
